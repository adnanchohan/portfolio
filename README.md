# Adnan C. — Independent Android Developer Portfolio

A lightweight, high-performance static portfolio website built for independent Android developers and solopreneurs. Inspired by warm editorial design aesthetics.

---

## 🚀 How to Host on GitHub Pages

This project is built using pure HTML5, Vanilla CSS, and JavaScript, making it **100% compatible with GitHub Pages** out of the box with zero build commands required.

### Step 1: Initialize Git & Commit
Open your terminal in this directory (`/Users/adnanchohan/portfolio`):

```bash
cd /Users/adnanchohan/portfolio
git init
git add .
git commit -m "Initial commit - Portfolio Website"
```

### Step 2: Push to GitHub
Create a new repository on GitHub (e.g. `portfolio` or `username.github.io`) and run:

```bash
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** > **Pages**.
3. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
4. Select **`main`** branch and `/ (root)` folder.
5. Click **Save**.

Your portfolio will automatically be live at: `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/` 🎉
